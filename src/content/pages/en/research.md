# Research

We study operating system design, performance, and security, from kernel components and multicore scalability to Rust, RISC-V, and systems for AI.

## Research interests

- **Operating Systems**: investigating the principles, design, and implementation of operating systems that need high performance and high availability with reduced overhead for emerging storage, networking, and computing architectures.
- Operating system performance optimization for multi-core architectures.
- Flexible OS kernel components across hardware privilege interfaces.
- Operating systems with customized hardware and languages, including Rust and RISC-V.
- Operating system vulnerability analysis.
- Operating system automatic updating.
- **AI4OS and OS4AI**: operating system support for AI workloads and AI-assisted system design, including resource scheduling, memory management, security, and reliability. See our [research opportunities](/join/) for specific topics.
